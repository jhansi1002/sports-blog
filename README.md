# 🏏 SportsBlog

**SportsBlog** is a full-stack web application built using the **MERN Stack** that delivers real-time cricket scores, sports articles, and blogs. The platform allows users to read, post, and interact with sports content, making it the go-to hub for sports fans.

---

## 🚀 Features

- ✍️ **Create & Manage Blogs** – Add, edit, or delete your own sports articles
- 🔍 **Search & Filter** – Quickly find content by sport or keyword
- 💬 **Comment System** – Readers can leave comments on posts
- 👤 **Authentication** – Secure user login using JWT

---

## 🛠 Tech Stack

### Frontend
- React.js
- React Router
- Axios
- Bootstrap / Tailwind CSS (choose one based on your UI)
  
### Backend
- Node.js
- Express.js
- JWT for Authentication

### Database
- MongoDB
- Mongoose

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/sportsblog.git
cd sportsblog
2. Install Dependencies
Frontend:
cd sportsblog
npm install
Backend:
cd backend
npm install

4. Run the App
Start Backend:
cd backend
node app.js
Start Frontend:
cd sportsblog
npm start
